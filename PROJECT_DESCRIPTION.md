# Interruptible Reasoning Dataset

This repository is the collaborative construction surface for the Stage 1
binary update-acceptance benchmark. It separates shared contracts, schemas,
source provenance, and validation from eight contributor-owned submission
areas.

The initial state is a scaffold, not a completed dataset. Source IDs and the
P1-P8 workload are generated from the 2026-08-03 design snapshot. Problem text,
gold answers, reasoning traces, authored update rows, and independent review
decisions remain pending.

The repository intentionally uses only Python's standard library for scaffold
generation, validation, and tests.
